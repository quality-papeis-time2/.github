## Guia Rápido de Acesso ao Repositório

O nosso repositório é **Privado** e o controle de acesso funciona de forma simples para garantir a segurança do projeto:

### 1. Integrantes do Time 2 (Permissão de Escrita — *Write*)
* **Quem são:** Os membros da equipe de Engenharia da Computação (Rafaela, Bianca e Gabriel).
* **O que podem fazer:** Acesso completo. Podem enviar códigos (`git push`), criar *branches*, editar arquivos e atualizar a documentação.

### 2. Professores e Outras equipes (Permissão de Leitura — *Read*)
* **Quem são:** Docentes, monitores e integrantes dos Times 1 e 3 convidados para a organização.
* **O que podem fazer:** Acesso de **Apenas Leitura**. Podem visualizar os arquivos, clonar o projeto e baixar todo o código em seu computador.

### 3. Visitantes sem convite
* Por se tratar de um repositório privado, pessoas não cadastradas na organização não conseguirão visualizar a página ou o conteúdo.

---

## Como solicitar acesso?

Se você é professor ou membro de outro time e precisa de acesso para visualizar o projeto:
1. Envie o seu **nome de usuário do GitHub** para um dos integrantes do Time 2.
2. Você receberá um convite por e-mail ou notificação no GitHub com permissão de **Leitura (*Read*)**.
3. Basta aceitar o convite para acessar o código e documentação!
